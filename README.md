# 🌐 Primeiro Site - Projeto HTML e CSS

Este é o meu primeiro site publicado na internet, desenvolvido com HTML e CSS como parte dos meus estudos em programação.

---

## 💡 Sobre o projeto

Este projeto foi criado com o objetivo de praticar:

* Estruturação de páginas com HTML
* Estilização com CSS
* Organização de layout
* Publicação de site utilizando GitHub Pages

---

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3

---

## 🌐 Acesse o site

👉 https://hdjlucas-maker.github.io/primeiro-site/

O principal objetivo deste projeto foi colocar em prática os conhecimentos iniciais em desenvolvimento web e entender como funciona a criação e publicação de um site.

## 📚 Aprendizados

Durante o desenvolvimento, aprendi:

* Como estruturar uma página web
* Como aplicar estilos com CSS
* Como organizar arquivos de um projeto
* Como publicar um site online
